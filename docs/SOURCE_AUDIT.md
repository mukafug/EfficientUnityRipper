## Decisions justified by the audit

Direct C# imports avoid web-HTML scraping and assumptions about nonexistent CLI options. All native serialized classes are walked, so coverage is not limited to meshes/textures or centered on Blender. Serialized data is preserved before editor/project processing. Dependencies, scene hierarchy and export closure are explicit; engine-injected/generated values are identified. GUI uses the upstream desktop dock workflow while adding Unity-specific evidence inspection. Durable cache/queue/object checkpoints are implemented because the audited upstream application does not provide that contract.

Upstream source was not modified or copied into the tracked repository. Backend project references the exact checkout during build; source/build scripts and dependency metadata make this decision reviewable. A source audit is not an end-to-end test of every upstream format. See VALIDATION.md for what actually ran.
